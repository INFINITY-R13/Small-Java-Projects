## ▶️ Running a Project

Clone the repository:

```bash
git clone https://github.com/INFINITY-R13/Small-Java-Projects.git

Navigate to the project you want to run:

```bash
cd Small-Java-Projects
cd Project-Name
```

Compile the Java program:

```bash
javac Main.java
```

Run it:

```bash
java Main
```

> Make sure the Java Development Kit (JDK) is installed on your system.
