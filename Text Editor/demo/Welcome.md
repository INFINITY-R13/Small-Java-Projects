# ✦ Welcome to AuraEdit

AuraEdit is a modern, aesthetic, and distraction-free text & code editor crafted in Java. Designed for speed, elegance, and delightful typography.

---

## ✨ Features at a Glance

- **Multiple Color Themes**: Catppuccin Mocha, Tokyo Night, Nord Frost, GitHub Light, and Solarized Warm.
- **Multi-Tab Workspace**: Open and manage multiple documents with ease.
- **Syntax Highlighting**: Real-time syntax coloring for Java, Python, JavaScript, JSON, Markdown, SQL, C++, and Shell.
- **Interactive Markdown Preview**: Click the eye icon `👁️` in the top right to toggle real-time rendered preview!
- **Sleek Sidebar Explorer**: Browse folders and project trees effortlessly.
- **Smart Editing**:
  - Auto-closing brackets and quotes: `()`, `[]`, `{}`, `""`, `''`
  - Intelligent auto-indentation on Enter
  - Bracket matching highlight
  - Current line background highlight
  - Duplicate lines (`Cmd/Ctrl + D`)
  - Comment toggle (`Cmd/Ctrl + /`)
- **Find & Replace**: Live document search highlights, match counter, case sensitivity, and whole-word matching.
- **High-DPI Retina Ready**: Vector-drawn icons and LCD anti-aliased typography.

## ⌨️ Keyboard Shortcuts

| Action | Shortcut |
|---|---|
| **New Tab** | `Ctrl / Cmd + N` |
| **Open File** | `Ctrl / Cmd + O` |
| **Open Folder** | `Ctrl / Cmd + Shift + O` |
| **Save Document** | `Ctrl / Cmd + S` |
| **Save As** | `Ctrl / Cmd + Shift + S` |
| **Close Tab** | `Ctrl / Cmd + W` |
| **Find in File** | `Ctrl / Cmd + F` |
| **Find & Replace** | `Ctrl / Cmd + H` |
| **Toggle Sidebar** | `Ctrl / Cmd + B` |
| **Switch Theme** | `Ctrl / Cmd + T` |
| **Zoom In / Out** | `Ctrl / Cmd + (+ / - / Wheel)` |
| **Reset Zoom** | `Ctrl / Cmd + 0` |
| **Undo / Redo** | `Ctrl / Cmd + Z` / `Shift + Z` |
| **Duplicate Line** | `Ctrl / Cmd + D` |
| **Toggle Comment** | `Ctrl / Cmd + /` |
